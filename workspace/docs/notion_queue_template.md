# Factory Queue Template

## Columns

- Issue ID (title)
- Status (select)
- Priority (select)
- Assignee (person)
- Due Date (date)
- Factory Branch (select: factory-1 / factory-2 / main)
- Gate Status (select: PASS / FAIL / ESCALATE)
- Agent Notes (rich text)

## Usage

Every new work item starts here. Nothing moves to code without a queue entry.
