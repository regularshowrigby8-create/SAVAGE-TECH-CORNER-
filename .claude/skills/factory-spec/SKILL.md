# Factory Spec Skill

## Four Gates Before Any Code Exists

1. **Intent Gate** — What does the user actually need? (Read CHARTER.md)
2. **Risk Gate** — What could break? What is the blast radius?
3. **Evidence Gate** — What artifacts prove this is needed?
4. **Contract Gate** — Does the spec match `docs/factory/CONTRACT.md`?

Only after all four gates are documented may code be written.
