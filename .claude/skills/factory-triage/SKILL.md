# Factory Triage Skill

## Purpose

Convert new work into labeled Linear issues.

## Procedure

1. Read the request.
2. Check `docs/factory/CHARTER.md` for applicable rules.
3. Create Linear issue with labels: `factory:triage`.
4. Update Notion database `Factory Queue`.
5. Comment on issue with `factory-triage` snapshot.

## Stop Conditions

- Issue has a priority, assignee, and due date.
- Notion database reflects the issue.
